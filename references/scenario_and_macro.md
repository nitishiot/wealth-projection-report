# Scenario bands & macro adjustment

## The temper-below-history principle

Trailing 5-yr CAGRs for Indian small/mid funds in a bull run (18-25%) cannot be
projected for 20 years. The gravity that long-run equity returns revert to is
**nominal GDP growth ≈ earnings growth ≈ real GDP + inflation ≈ ~11%** (India,
current). Set base cases near or modestly above that for higher-risk categories,
and keep even the optimistic band below recent history. Let the user edit any
band in the report.

## Macro-adjusted layer

Make today's backdrop explicit as a second, lower scenario set. Research and
state the current numbers (search, cite):
- Real GDP growth, CPI inflation, RBI repo rate → derive the ~nominal-GDP anchor.
- Index valuations: Nifty 50 / Midcap 150 / Smallcap 250 P/E vs their 7-yr
  medians. Rich = expect a **de-rating drag**; near-average = minimal drag.

### How valuations feed the adjustment
- The building block: long-run return ≈ earnings growth (~nominal GDP) + dividend
  ± valuation change.
- If a segment is expensive (e.g. small-cap P/E ~19% above median), expect a
  **de-rating drag concentrated in the first ~3-7 years**, then mean reversion.
- Because the user invests via SIP over many years, the drag is *softened* —
  later contributions buy in at cheaper valuations if de-rating happens.
- Net effect today: at rich small/mid valuations, forward returns across caps sit
  **closer together** than history implies. Reflect this by trimming the base by
  ~1-1.5% for stretched categories.

### Suggested macro-adjusted bands (when small/mid are richly valued)
Small 8.5 / 11.5 / 14 · Mid 8.5 / 11.5 / 13.5 · Large&Mid 8 / 11 / 13 ·
Flexicap 8.5 / 11 / 13. Recompute from the anchor if macro conditions differ.

## Honesty notes to include in the report
- Nobody forecasts 20 years of GDP, elections, or geopolitics — treat the
  *range*, not the point estimate, as the answer.
- The valuation drag is a timing effect, not a permanent lower ceiling; a
  correction in the next few years can actually help a long-horizon SIP.
